# Akan Name Generator

##  Description

The Akan Name Generator is a simple web application that calculates the day of the week a person was born and assigns the corresponding Ghanaian Akan name based on their gender.


##  Author

Warren Bett

##  Features

- Enter birth day, month, and year
- Select gender (Male or Female)
- Calculates the day of the week
- Displays the corresponding Akan name
- Input validation to ensure correct values

##  Technologies Used

- HTML5
- CSS3
- JavaScript


##  How to Use

1. Enter your birth day.
2. Enter your birth month.
3. Enter your birth year.
4. Select your gender.
5. Click the **Generate Akan Name** button.
6. Your Akan name and the day you were born will be displayed.
